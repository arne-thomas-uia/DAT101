## 📚 The 10 Core Elements of This Course
All the assignments in this repository are built around 10 fundamental concepts of programming. We use modern JavaScript (ES6+), and you will master the following:

### 1. Variables and Simple Objects
Variables are containers for storing data. In this course, we strictly use modern syntax: `let` (for values that can change) and `const` (for values that stay the same). *Rule of thumb: We NEVER use the old `var` keyword!*

### 2. Data Types
JavaScript is a "loosely typed" language (it figures out the data type automatically). However, to be a good programmer, you should think about data like in "strongly typed" languages (like C++). We will work with specific types such as Strings (text), Integers (whole numbers), Floats (decimals), and Booleans (true/false).

### 3. Operands and Operators
The tools for doing math and manipulating data. You will use standard operators like addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`).

### 4. Logical Tests (Comparisons)
Before a program can make a decision, it needs to evaluate a condition. We use strict operators like `===` (strictly equal), `!==` (strictly not equal), `<=`, and `>=`. 
*⚠️ **Warning:** We will learn why the regular `==` in JavaScript is tricky and should generally be avoided!*

### 5. If-Statements
This is how your code makes decisions based on the logical tests. *"If this is true, do X; otherwise, do Y."*

### 6. Loops
Computers are great at repetitive tasks. Loops (`for`, `while`) allow you to run the same block of code multiple times without writing it over and over again.

### 7. Arrays (Tabeller)
Arrays are lists. They allow you to store multiple values (like a list of user names or color codes) inside a single variable.

### 8. Functions
Functions are reusable blocks of code designed to perform a particular task. Think of them like "Actions" in Photoshop—you set them up once, and trigger them whenever you need them.

### 9. Classes
The blueprint for creating objects. This is your introduction to Object-Oriented Programming (OOP), allowing you to structure your code logically by grouping related data and functions together.

### 10. The DOM (Document Object Model)
This is where the magic happens for designers! The DOM is the bridge between your HTML structure and JavaScript. You will learn how to use JS to dynamically change, animate, and interact with the elements on your web page.
